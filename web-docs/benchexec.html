Benchexec Installation Instructions

  1. I'm building Python3.9 from source in the tomcat home folder like this:
    sudo yum install gcc openssl-devel bzip2-devel libffi-devel zlib-devel \
libsqlite3x-devel sqlite-devel xz-devel tk-devel uuid-devel readline-devel \
libdb-devel gdbm-devel ncurses-devel
wget https://www.python.org/ftp/python/3.9.6/Python-3.9.6.tgz
tar -xvf Python-3.9.6.tgz
./configure 
make
sudo make altinstall
  2. After the altinstall line above, we have /usr/local/bin/python3.9 and can pip install benchexec:
    sudo /usr/local/bin/python3.9 -m pip install benchexec

  3. Then we can setup the Cgroups stuff:
    see here and here:
    sudo groupadd benchexec
sudo usermod -a -G benchexec tomcat
sudo usermod -a -G benchexec sandbox
sudo usermod -a -G benchexec sandbox2
sudo curl -o /etc/systemd/system/benchexec-cgroup.service https://raw.githubusercontent.com/sosy-lab/benchexec/main/debian/benchexec-cgroup.service
systemctl daemon-reload; systemctl enable --now benchexec-cgroup
