xCAT Installation

I. Pre-install

1. Legend
a. Internal BMC IP of compute nodes: 172.29.101.1 – 172.29.101.32
b. Internal BMC IP of headnode: 10.141.248.99 (se_m1, se_login1, starexec)
c. Internal BMC Network IP for headnode: 172.29.101.254
c. Internal IP of headnode: referred to as (xcat_int_ip) 10.10.2.254 (eno1)
d. Internal IP of compute nodes: 10.10.2.1 – 10.10.2.32
e. External IP (internet connected) of headnode: referred to as (xcat_ext_ip) 10.141.248.100 (eno2,eth1)
f. External DNS server IP: referred to as (dns_ext_ip) 10.10.2.254
g. Cluster domain: referred to as (cluster_dom) starexec.miami.edu

2. Network Wiring
a. IMM2 is attached to private network, switch that the compute nodes are attached to
b. eno1 is attached to private network, switch that the compute nodes are attached to
b. eno1:0 is 172.29.101.254
c. eno2 is attached to corporate network

The starexec cluster is not on the CCS 172.29.101.x private subnet. It and it’s IMM2 is on it’s own separate, isolated, private 172.29.101.x subnet. 172.29.101.x is the default subnet used by Lenovo for IMM2 (BMC). The BMC is IBM/Lenovo’s Baseboard Management Controller. The compute nodes share their IMM2 port with the OS as eno1. The headnode does not share its IMM2 port.

3. Prepare the Management Node
a. Install CentOS 7.4 on the Management Node
b. Setup Networking

[root@se_m1 ~]# systemctl stop firewalld
[root@se_m1 ~]# systemctl mask firewalld
[root@se_m1 ~]# yum install iptables-services -y
[root@se_m1 ~]# systemctl enable iptables

[root@se_m1 ~]# cd /etc/sysconfig/network-scripts/

[root@se_m1 ~]# vim ifcfg-eno1
[root@se_m1 ~]# cat ifcfg-eno1
TYPE=Ethernet
BOOTPROTO=static
DEFROUTE=yes
# IPADDR=172.29.101.100
IPADDR=10.10.2.254
MASK=255.255.255.0
NAME=eno1
UUID=01134419-2213-4c3a-9bdb-8182c22b2a89
DEVICE=eno1
ONBOOT=yes

[root@se_m1 ~]# cp ifcfg-eno1 ifcfg-eno1:0
[root@se_m1 ~]# vim ifcfg-eno1:0
[root@se_m1 ~]# cat ifcfg-eno1:0|egrep "IPADDR|DEVICE"
IPADDR=172.29.101.100
# IPADDR=10.10.2.254
DEVICE=eno1:0
# vi /etc/sysconfig/network-scripts/ifcfg-eno2
TYPE=Ethernet
BOOTPROTO=static
DEFROUTE=yes
NAME=eno2
UUID=63000c90-8718-4e77-9bcd-adc2346fa393
DEVICE=eno2
ONBOOT=yes
IPADDR=10.141.248.100
MASK=255.255.252.0
GATEWAY=10.141.248.1

[root@se_m1 ~]# service network restart
[root@se_m1 ~]# iptables -t nat -A POSTROUTING -o eno2 -j MASQUERADE
[root@se_m1 ~]# service iptables save
[root@se_m1 ~]# echo 1 > /proc/sys/net/ipv4/ip_forward
[root@se_m1 ~]# cat /etc/sysctl.conf | grep net.ipv4.ip_forward
net.ipv4.ip_forward = 1

[root@se_m1 ~]# vi /etc/resolv.conf
nameserver 10.10.2.254
nameserver 129.171.32.1
search se_m1.miami.edu
