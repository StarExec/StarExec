Compute Node MAC addresses

Get MAC Addresses of n0XX (ie n032)

Connect to the node's remote console 
[root@se-m1 ~]# chdef n0XX cons=ipmi
[root@se-m1 ~]# rcons n0XX
In a second terminal, start the node 
[root@se-m1 ~]# rpower n0XX on
Get the MAC Addresses from the Network configuration window in the Bios. Then power down the node. 
[root@se-m1 ~]# rpower n0XX off
